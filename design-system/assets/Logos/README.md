Option B, the proposed cut-paper VIA wordmark, in four inks. Option A (VIA's existing gold mark) is not included: use VIA's own master file.

- `via-mark-b-ink.svg`: ink `inchiostro` letters, `zafferano` sun. On bianco, muro and zafferano fields.
- `via-mark-b-paper.svg`: `on-dark` letters, `zafferano` sun. On mattone, oliva, prugna and inchiostro.
- `via-mark-b-on-saffron.svg`: ink letters, `mattone` sun. On zafferano only.
- `via-mark-b-one-colour.svg`: all `inchiostro`. One-colour print, stamps, embossing.

Clear space equals the sun's height on every side. Minimum width 64px on screen, 18mm in print.
