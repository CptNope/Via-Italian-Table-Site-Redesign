A cut-paper button: square corners, `paste` shadow, `label` type (width 85, weight 800, uppercase).

Variants by class: `btn` (mattone, the primary action: Book), `btn--sun` (zafferano with inchiostro text), `btn--paper` (bianco), `btn--plum` (prugna), `btn--ink` (inchiostro), `btn--ghost` (2px inset outline in the current text colour, for secondary actions on a coloured field).

- Use one `btn` (mattone) per view for the main action; on a mattone field, use `btn--sun` or `btn--paper` instead.
- Labels name what happens. An icon goes before the label, an arrow after it.
- Minimum height 48px (44px in the masthead). Hover lifts 2px with the `lift` shadow.
- The consumer provides the label, an optional inline icon (`currentColor`) and the link.
